# MiniXX Log Analyzer V4.2.3

Browser-based MiniXX fuel correction, before-after Log comparison, actual ignition-angle analysis, and local fuel-map screenshot recognition. V4.2.3 uses 20 RPM columns from 800 to 16000 in 800 RPM steps for both fuel and ignition, 0.8-step suggestions when a fuel map is available, AFR-difference display when it is not, selectable sample thresholds, collapsible diagnostics, and bounded local OCR.
